# Contributing to RoadResQ

Thank you for contributing to **RoadResQ**!

---

## Code Quality Standards

1. **Python**: All code must conform to `ruff` formatting and pass `mypy` strict type checking.
2. **TypeScript**: Strict mode enabled. All code must pass `tsc --noEmit` and `eslint`.
3. **Commit Messages**: Follow standard conventional commit format:
   - `feat(scope): ...`
   - `fix(scope): ...`
   - `chore(scope): ...`
   - `docs(scope): ...`

---

## Development Cycle

```text
Create Branch -> Implement -> Test Locally -> Push -> Create PR -> CI Checks -> Review -> Merge
```
